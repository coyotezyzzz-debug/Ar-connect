# ArConnect - Marketplace de Climatização em Manaus

Plataforma moderna para agendamento de técnicos de ar-condicionado em Manaus, AM.

## 🚀 Funcionalidades

- **Agendamento 100% Livre e Sem Cadastro**: Solicitação direta para o WhatsApp do profissional homologado com mensagem pré-formatada (aparelho, serviço, data e bairro).
- **Cobertura Completa em Manaus**: Adrianópolis, Parque 10, Vieiralves, Ponta Negra, Flores e todas as zonas da cidade.
- **Busca por CEP**: Preenchimento automático do bairro via integração com ViaCEP.
- **Painel Administrativo (`/admin`)**: Gerenciamento de técnicos homologados, cadastro com validação de CEP e moderação de avaliações.
- **Design Responsivo & Mobile-First**: Otimizado para navegação rápida e proporcional em smartphones.

## 🛠️ Tecnologias

- HTML5 / CSS3 (Tailwind CSS)
- JavaScript (ES6+)
- Node.js (Servidor HTTP nativo com API REST)
- Google Material Symbols

## 📦 Como Rodar o Projeto

```bash
# Instalar dependências (se houver)
npm install

# Iniciar o servidor
npm start
# ou
node server.js
```

Acesse no navegador: `http://localhost:3000`
